# 책피바라 | 2026 독서 전시 웹사이트 v14

## 실행
- `index.html`을 Chrome, Safari, Edge에서 실행합니다. 별도 설치/빌드 도구가 없습니다.
- 메인에서 『하늘과 바람과 별과 인간』 또는 『호의에 대하여』를 선택합니다.
- 두 책의 체험을 마친 후에는 `footsteps.html`에서 활동 사진과 실제 기록을 보며 마무리할 수 있습니다.
- GitHub Pages는 파일 전체를 저장소 최상위에 업로드하고 Settings → Pages → Deploy from a branch → main / (root)에서 공개합니다. 공개 링크는 이 파일만으로 자동 생성되지 않습니다.

## 구성
1. `index.html`: 팀 소개, 주제, 두 책의 실물 표지 선택, 별도 활동기록으로 가는 짧은 링크
2. `book1.html`: 스크롤 스냅 방식 우주 전시, 책 표지·완전 암전·4가지 층위·빅뱅·1권 독서토의 사진 카드
3. `book2.html`: 실제 표지로 시작, 첫 화면 한 번 터치 → **별도 입체 책 펼침 → 펼쳐진 페이지에 줌인** → 이야기형 장면 전환(모의재판/판결/우체통/편지)
4. `footsteps.html`: **우리의 발자취** 독립 페이지. 1~5차 실제 활동보고서의 활동 기록, 사진, 마지막 처음 주제 문장(수미상관)
5. `data.js`: 활동 텍스트, 표지/사진/배경 경로, 편지 메시지, 사이트 문구를 관리하는 편집용 파일

## v14 주요 수정
- 2권 데스크톱의 기록·재판·우체통·감사 편지 화면을 넓히고 본문, 역할 이름, 버튼과 상세 열람 창의 글씨를 확대했습니다. 모바일용 배치는 유지했습니다.
- 1권 마지막 활동 카드의 세로 내부 스크롤을 제거했습니다. 카드 전체는 기존처럼 가로로 탐색하며, 사진을 누르면 확대됩니다. 향후 110자보다 긴 요약이 추가되면 별도의 전체 기록 열람 창을 사용합니다.
- 닫힌 봉투 속 종이는 밖으로 드러나지 않으며, 개봉 중에는 빈 편지지만 올라옵니다. 편지지가 확대되어 멈춘 뒤 제목·본문·발신자가 나타납니다.
- 메인, 네 가지 색의 빅뱅, 배경과 활동 사진, data.js의 실제 활동 내용은 유지했습니다.

## v13 주요 수정
- 홈: 실물 표지 두 권을 크게 보여주는 표지 중심 레이아웃. 한 번의 짧은 휠/스와이프로 다음 전체 화면(우리의 발자취 입구)으로 정렬합니다.
- 1권: 기존 스크롤·암전·층위 전시·내용을 유지하고, 빅뱅에서 네 가지 색(청록/초록/주황/보라)이 화면에 따로 나타나 이동한 뒤 폭발하도록 새로 구현했습니다. 별자리 연결선과 기존 단일 원형 빛은 빅뱅에 사용하지 않습니다.
- 2권: 기존 8장면과 인터랙션을 유지합니다. 서문과 엔딩의 종이 카드 대신 풍경 위 서정적인 타이포그래피, 은은한 햇살과 부유하는 빛, 사건 기록의 집중 조명, 봉투 개봉 애니메이션, 따뜻한 편지 읽기 화면을 적용했습니다.
- `data.js`와 실제 활동 사진·표지·배경은 v12에서 그대로 보존합니다.

## v12 주요 수정
- 2권의 기존 '표지 자체 확대'를 폐기하고, 실제 책 표지는 처음 화면에만 유지. 입장 시 별도의 책 펼침 오브젝트를 보여준 다음 페이지 안으로 확대하도록 변경했습니다.
- 모바일(390×844/360×740)에서 챕터 카드와 글자 정렬, 편지지 제목·본문·발신자를 수정했습니다. 편지·메시지·판결 비교 모달 동작을 점검했습니다.
- 실제 재판 사진이 없으므로 11월 21일 모의재판 썸네일은 **일러스트**로 교체하고 '실제 활동 사진이 아닙니다'라는 설명을 표시했습니다. 보고서의 식사/모임 사진을 재판 진행 장면이라고 주장하지 않습니다.
- 홈에서 긴 사진 타임라인을 빼고, 두 책의 경험 끝에 '우리의 발자취'를 두었습니다. 마지막에는 **원자에서 호의까지 — 세상은 어떻게 연결되어 있는가**라는 첫 문장을 정확히 다시 사용합니다.
- 1권의 타임라인 장면에 실제 활동 사진이 있습니다. 다만 4개 층위별 실물 전시 사진을 정확히 연결할 자료가 없어 해당 칸에는 임의 사진을 넣지 않았습니다.

## 사진과 자료의 사용
- 실제 표지 2장: 사용자가 제공한 도서 표지 이미지.
- 활동 사진: 사용자 제공 1~5차 PDF 결과보고서에 실린 사진을 이미지로 분리한 것.
- 모의재판 일러스트(`images/mock-trial-illustration.png`): 이번 v12에서 제작한 디자인 이미지, **실제 재판 사진이 아님**.
- 행사 사진 속 인물은 공개 배포 전에 당사자 동의를 확인해 주세요.

## 내용 수정
`data.js`에서 다음 항목을 바꾸면 됩니다.
- `DATA.site`: 팀명, 활동 주제와 소개문
- `DATA.books`: 책 제목·표지·배경 이미지 경로
- `DATA.timeline`: 날짜, 실제 활동 요약, 첨부 사진 경로
- `DATA.gallery.panels`: 네 층위별 닉네임, 전시 사진, 책 구절 및 개인 소감
- `DATA.trial`: 모의재판 사건, 역할, 판결 비교
- `DATA.mailbox`: 받은 메시지, 실제 Google Form URL(`formUrl`)
- `DATA.letters`: 감사 편지 작성 소감과 닉네임
- `DATA.footsteps`: '우리의 발자취' 페이지의 문구와 사진 캡션
- `DATA.conclusion.sentence`: 팀이 **직접 확정한** 결론 한 문장 (아직 자리표시)

참고: 보고서 5회 중 11월 21일에는 과학관과 모의재판 두 활동을 함께 해서 타임라인에서 6개 카드로 분리합니다.

## 아직 필요한 자료
1. 과학관 4개 담당 전시(빛·자외선 / 몸짓·소리 / AI 윤리 게임 / 우주 환경)의 사진 각 1~2장
2. 실제 모의재판 사진이 있다면 선택적으로 일러스트와 교체 가능
3. 감사 편지 사진/원문(받는 사람 가림 처리), 팀원별 닉네임
4. Google Form URL
5. 팀에서 합의한 '우리의 한 문장'. 단, 수미상관 엔딩의 주제 문장은 이미 본문과 정확히 동일하게 연결되어 있습니다.

## 테스트 범위
- Chromium 에뮬레이션으로 390×844 및 360×740 모바일 화면의 메인·2권 장면과 실제 책 펼침을 캡처했습니다.
- 390px 뷰포트에서 우체통 메시지, 편지, 판결 비교 확대창이 화면 안에 렌더링되고 JavaScript 오류가 보고되지 않았습니다.
- 1440×900 데스크톱에서 2권 입장과 펼친 책, 편지 화면 및 가로 넘침이 없는 것을 확인했습니다.
- `footsteps.html` 모의재판 일러스트 로딩, 마지막 주제 문장, 실제 사진 타임라인이 보이는 것을 확인했습니다.
- 실제 사용자의 물리적 휴대폰과 모든 기기에서의 체감 성능까지 검증한 것은 아닙니다.

## v13 점검 범위

- 로컬 HTTP 주소가 테스트 환경에서 차단되어 이미지·코드를 내장한 독립 HTML을 브라우저에 불러오는 방식으로 검사했습니다.
- 검사 중 JavaScript 실행 오류와 가로 넘침은 발견되지 않았습니다. 실제 휴대폰과 다른 브라우저에서의 체감 성능은 별도 확인이 필요합니다.
